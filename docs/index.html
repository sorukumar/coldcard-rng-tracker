The Attacker Evolved

Unique Insight · Fee & Tactic Analysis

Between Wave 1 and Wave 3, the attacker completely changed their consolidation strategy — a real-time adaptation to community detection efforts.

The tactical evolution tells a story: Wave 1 used shared collector addresses — easy to identify and track. As the community began flagging those addresses in real time, the attacker adapted. Wave 3 swept every single victim into its own unique, freshly-generated P2WSH vault. The only signal remaining was the fee rate: 201.0 sat/vB when the network was clearing transactions at ~3 sat/vB. A rate that constant across 1,626 unrelated sweeps is hardcoded in a script — not independently chosen by 1,626 different people.

Firmware Vulnerability Matrix

Seeds generated on affected firmware operated on a structurally flawed RNG. Updating firmware does not repair an existing seed — you must generate a new seed on fixed firmware.
